## Estructura del proyecto

Cada componente es independiente y sigue la misma organización:

```text
├── 01-glass-shimmer-company-switcher/
│   ├── index.html
│   ├── style.css
│   └── script.js
├── ...
└── 09-saas-kpi-cards-sparklines/
    ├── index.html
    ├── style.css
    └── script.js
```

## Cómo usarlos localmente

1. Clona este repositorio:
   ```bash
   git clone https://github.com/TU_USUARIO/codepen-componentes.git
   ```
2. Entra en la carpeta del componente que quieras probar y abre su archivo `index.html` en tu navegador (o usa una extensión como *Live Server*).
